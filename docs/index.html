🎯 DARTUNITY

GranBoard ↔ Autodarts

Einrichtung in wenigen Schritten – ganz ohne Kopieren von Script-Code.

1. Welches Gerät nutzt du?

Bitte Gerät auswählen.

2. Installation

1Tampermonkey installieren

Installiere die Erweiterung aus dem offiziellen Chrome Web Store. Bestätige die Installation im Browser.

Tampermonkey öffnen ↗

2Userscripts zulassen

Öffne Chrome → Erweiterungen → Erweiterungen verwalten → Tampermonkey → Details. Aktiviere dort „Userscripts zulassen“, sofern der Schalter angezeigt wird. Je nach Chrome-Version kann auch der Entwicklermodus relevant sein.

Diese Sicherheitsfreigabe musst du selbst vornehmen. Die Setup-Seite kann sie nicht automatisch einschalten.

1Edge und Tampermonkey

Öffne diese Seite in Microsoft Edge für Android. Gehe über das Edge-Menü zu Erweiterungen und installiere Tampermonkey, falls es in deiner Edge-Version angeboten wird.

Tampermonkey-Informationen ↗

2Erweiterung aktivieren

Prüfe in Edge, ob Tampermonkey eingeschaltet ist und Scripts auf Autodarts ausführen darf.

Android Edge, Tampermonkey und Web Bluetooth müssen zusammen funktionieren. Die tatsächliche GranBoard-Verbindung testen wir anschließend; eine erfolgreiche Script-Installation allein garantiert sie nicht.

3Dartunity-Script installieren

Empfohlener Weg (auch wenn Chrome nur Quelltext anzeigt): Öffne das Tampermonkey-Symbol → Übersicht → Reiter Hilfsmittel → Von URL installieren. Kopiere dafür die Script-Adresse mit dem Button unten, füge sie dort ein und bestätige die Installation in Tampermonkey.

Alternativ: Direktlink ausprobieren

Bei manchen Browser-Konfigurationen öffnet Tampermonkey den Installationsdialog direkt. Wenn stattdessen Quelltext erscheint, nutze den Weg über „Hilfsmittel“ oben.

Direktlink öffnen ↗

Wenn das Script bereits installiert ist, kann Tampermonkey „Neu-Installation“ anzeigen. Das kann bestehende Script-Einstellungen zurücksetzen. Nicht bestätigen, wenn du sie behalten möchtest.

4Autodarts starten

Öffne Autodarts im selben Browser, melde dich an und nutze die GranBoard-Verbindungsfunktion des Scripts. Erlaube die Bluetooth-Geräteauswahl, wenn der Browser danach fragt.

Autodarts öffnen ↗

5Verbindung testen

Starte ein Testspiel und kontrolliere, ob Würfe vom GranBoard in Autodarts ankommen. Wenn nicht, prüfe zuerst Script-Aktivierung, Bluetooth und Browserberechtigungen.

Hilfe & Updates

Das Dartunity-Script kann Updates automatisch über GitHub beziehen. Bei Problemen melde den Fehler mit Gerät, Browser-Version und einer kurzen Beschreibung.

🎯 DARTUNITY

GranBoard ↔ Autodarts

Einrichtung in wenigen Schritten – ganz ohne Kopieren von Script-Code.

1. Welches Gerät nutzt du?

Bitte Gerät auswählen.

2. Installation

1Tampermonkey installieren

Installiere die Erweiterung aus dem offiziellen Chrome Web Store. Bestätige die Installation im Browser.

Tampermonkey öffnen ↗

⚠️ WICHTIG! Unbedingt „Nutzerscripts zulassen“ einschalten!

Ohne diesen Schalter läuft unser Dartunity-Script nicht! In Google Chrome muss diese Berechtigung nach der Tampermonkey-Installation manuell aktiviert werden.

So geht’s:

  1. Öffne in Chrome die Adresse chrome://extensions/.
  2. Klicke bei Tampermonkey auf Details.
  3. Scrolle zu „Nutzerscripts zulassen“ und schalte den Regler EIN (blau).
  4. Kehre danach zu dieser Seite zurück und installiere unser Dartunity-Script.

🔎 Kontrolle: Der Schalter „Nutzerscripts zulassen“ muss blau sein. Erst dann mit Schritt 3 weitermachen.

1Edge und Tampermonkey

Öffne diese Seite in Microsoft Edge für Android und tippe auf „Tampermonkey installieren“. Bestätige die Installation der Erweiterung in Edge.

Tampermonkey installieren ↗

Falls der Store-Link auf deinem Handy nicht direkt die Installation anbietet: Edge-Menü ☰ → Erweiterungen → Tampermonkey auswählen und installieren.

2Erweiterung aktivieren

Prüfe in Edge, ob Tampermonkey eingeschaltet ist und Scripts auf Autodarts ausführen darf.

Android Edge, Tampermonkey und Web Bluetooth müssen zusammen funktionieren. Die tatsächliche GranBoard-Verbindung testen wir anschließend; eine erfolgreiche Script-Installation allein garantiert sie nicht.

3Dartunity-Script installieren

Klicke auf den Button. Tampermonkey öffnet die Installationsansicht. Bestätige dort Installieren.

🎯 Dartunity-Script installieren ↗

Erfolgreich mit Windows und Google Chrome getestet. Android Edge wird noch getestet.

Falls die Installation nicht automatisch öffnet

Öffne Tampermonkey → Übersicht → Hilfsmittel → Von URL installieren. Kopiere die Script-Adresse und füge sie dort ein.

Falls das Script schon installiert ist und „Neu-Installation“ erscheint: Nicht bestätigen, wenn du bestehende Einstellungen behalten möchtest.

4Autodarts starten

Öffne Autodarts im selben Browser, melde dich an und nutze die GranBoard-Verbindungsfunktion des Scripts. Erlaube die Bluetooth-Geräteauswahl, wenn der Browser danach fragt.

Autodarts öffnen ↗

5Verbindung testen

Starte ein Testspiel und kontrolliere, ob Würfe vom GranBoard in Autodarts ankommen. Wenn nicht, prüfe zuerst Script-Aktivierung, Bluetooth und Browserberechtigungen.

Hilfe & Updates

Das Dartunity-Script kann Updates automatisch über GitHub beziehen. Bei Problemen melde den Fehler mit Gerät, Browser-Version und einer kurzen Beschreibung.
